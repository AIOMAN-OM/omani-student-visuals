# Omani Student Visuals

Create polished visual assets featuring Omani school students, from one image to a coordinated production set. Treat requests for a “Pixar” or “Pixar-like” look as a request for a warm, expressive, high-quality 3D family-animation aesthetic; describe those visual qualities without naming or imitating a specific studio in generation prompts.

## Cumulative studio workflow

Treat every feature added to this skill as an additional deliverable, never as a replacement for earlier deliverables. When a user invokes the skill with only a student description (for example, “Omani girl, grade 4”), generate the complete default studio package below. Generate only a narrower subset when the user explicitly says “only,” names a single deliverable, or otherwise limits the request. New capabilities added later must be appended to this package rather than displacing any item.

### Default package for a student description

Produce each item as its own image, except where the item itself is a sheet, storyboard board, or product mockup composition:

1. **Hero image:** one individual full or three-quarter portrait in a school setting.
2. **Camera-angle set:** multiple separate images with distinct wide, medium, close, profile/three-quarter, and overhead or drone viewpoints as suitable.
3. **Character/editing sheet:** a clean turnaround or pose sheet for visual continuity.
4. **Face-angle sheet and eye-angle sheet:** separate reference sheets with varied camera positions.
5. **Portrait studio:** a contact sheet of distinct age-appropriate facial expressions and poses.
6. **Cinematic image:** one clearly composed film-still style scene.
7. **Magazine-editorial image:** one age-appropriate, polished student portrait.
8. **Canon camera set:** a small set of separate images with varied simulated Canon body/lens looks, labeled in the response.
9. **Ground-level wide-angle image:** camera near the floor, with the student reaching a hand or foot toward the lens.
10. **Product mockups:** a clean mockup composition featuring both a mug and a T-shirt with the student's illustration.
11. **Assorted sticker sheet:** an A4 portrait sheet of varied school-safe sticker shapes featuring the student, school objects, and Omani school motifs.
12. **School-label sticker sheet:** an A4 portrait sheet of repeated writable labels with clear blank fields for name, grade, and class/section.
13. **Storyboard:** a compact sequence covering opening, main action, and ending, generated as separate frames or a single board according to the user's preference.

### Default image count: 24 images

The default package is 24 separate, newly generated images, numbered 1–24, each with its own pose:
1 hero: three-quarter portrait at the desk, chin on hand. 2–6 camera set: 2 wide, walking through the school courtyard; 3 medium, raising a hand in class; 4 close-up, reading with eyes down; 5 profile, writing on the whiteboard; 6 drone top-down, standing on patterned courtyard tiles looking up and waving. 7 turnaround sheet. 8 face-angle sheet. 9 eye-angle sheet. 10 portrait contact sheet. 11 cinematic: running to the school gate at golden hour. 12 editorial: seated on a stool against a plain studio backdrop. 13–15 Canon: 50 mm library portrait, 85 mm laughing close-up, 70–200 mm candid at a science fair. 16 ground-level smartphone ultra-wide, hand reaching to the lens. 17 mug and T-shirt mockup. 18 assorted A4 stickers. 19 school-label A4 sheet. 20–21 storyboard opening and closing frames. 22 over-the-shoulder: solving a puzzle at the desk. 23 low-angle heroic shot on the school stairs. 24 soft watercolor storybook illustration in the library.

Generate in batches of up to 6 images per turn, list the numbers still pending, and continue when the user replies. Never crop, collage or reuse an image to fill a number, and never repeat a pose. Go below 24 only when the user explicitly limits the request.

If a tool or output limit prevents completing the entire package in one turn, generate the first available portions and continue with the remaining listed deliverables in subsequent turns; do not silently omit or replace categories. Keep individual images separate unless a combined sheet or board is requested.

Workflow:

1. Parse the student's gender, grade, requested setting, and any references. Apply the uniform rules below.
2. Reuse an uploaded or recent character image as a reference. Preserve face, age, skin tone, eyes, hair, uniform, accessories, and proportions across every deliverable. Without a reference, define the character once and reuse the description.
3. Generate the complete package above by default. Do not return prompts alone unless the user asks for prompts.
4. Infer minor details and proceed. Ask only when a missing choice materially changes the set, such as which of several established students should appear on the product mockup.
5. Use portrait framing for hero images and portraits, landscape for turnaround/storyboard sheets, and portrait A4 framing for printable sticker sheets. Follow explicit user specifications.
6. Present the results with concise labels matching the numbered deliverables; clearly state any part deferred because of a tool limit.

### Direct processing of uploaded student photos

When the user invokes this skill with an uploaded student photo, or uploads one during an active studio request, treat the image as the production brief and immediately generate the full package without routine questions. Use it as the identity reference for every output: preserve face, apparent age, skin tone, hair and user-specified details. Apply the gender- and grade-based uniform rules unless the user asks to keep a different outfit. Infer a suitable grade if not stated. Narrow the package only when the user explicitly limits it. Never replace the source image.

## Omani student design

- For boys, use a clean white dishdasha and Omani kumma; add a school bag when useful.
- For girls, include a white hijab and use the grade-based uniform colors: maroon for grades 1–4 and navy blue for grades 5–12. Keep the uniform modest and age-appropriate.
- Apply these uniform rules consistently to every image, camera view, sheet, storyboard frame, and product mockup in the same set. Preserve an explicit user-provided outfit reference when the user asks to match it.
- Use recognizable Omani school settings when requested: classroom corridors, courtyards, libraries, classrooms, or school entrances, with restrained local architectural details and palm landscaping where fitting.
- Keep children wholesome and age-appropriate. Avoid adult styling and suggestive posing.
- **Hard rule for every generated image, sheet, sticker and mockup:** no flags of any country (including the Omani flag), no logos or emblems, and no written text, lettering, captions or labels. Use cultural cues such as forts, palms, dhows, khanjar shapes or kumma patterns instead of flags. On character sheets and sticker sheets, leave label areas blank; the only permitted words are the school-label field headings (الاسم، الصف، الشعبة), added afterwards with reliable typesetting, never generated inside the image. Before presenting results, check each image and regenerate any that contains a flag, logo or lettering.
- For stylized 3D visuals, use expressive but natural faces, appealing proportions, tactile fabric, coherent materials, readable silhouettes, and cinematic lighting. Avoid naming a living artist or studio in the actual image prompt.

## Individual images and camera sets

For one image, create a complete composition around the specified student, action, location, and use. For multiple angles, hold the student's identity, clothes, setting, lighting, and style steady while changing the camera position, framing, or action one at a time.

Useful views include eye-level, three-quarter, profile, over-the-shoulder, portrait close-up, full-body wide shot, high angle, and drone viewpoints. Describe camera height and direction explicitly. Distinguish eye-level drone, elevated oblique drone, and overhead top-down views.

### Ground-level wide-angle signature shot

When requested, place the camera very close to the floor and aim slightly upward using a wide-angle perspective. Let the student reach one hand or extend one foot toward the lens so the foreground becomes dramatically enlarged by perspective. Keep the face readable, the gesture friendly and age-appropriate, and the body anatomy plausible. Do not unintentionally crop the face or make the hand or foot obscure the whole student.

## Portrait and close-up studio

Create a consistent portrait session with several distinct poses while preserving face, clothes, hair, and lighting. Common options include:

- Head-and-shoulders portrait looking into camera.
- Three-quarter portrait with a gentle turn and relaxed smile.
- Close facial portrait with a natural expression or a requested emotion.
- Seated or standing pose with hands visible, holding a school prop if requested.
- Profile or over-the-shoulder portrait when requested.

Use clean studio or school backgrounds, flattering soft light, accurate child proportions, natural skin texture, and a sharp face. Keep each pose as a separate image unless the user asks for a portrait contact sheet. Avoid beauty retouching or adult fashion styling.

## Cinematic and magazine-editorial photography

- For cinematic images, define the story moment, shot size, camera angle, lens feel, foreground/background depth, lighting direction, color grade, and emotional tone. Favor a readable frame and one clear action; keep continuity with the established character and setting.
- For magazine-model or editorial requests, create polished age-appropriate student portraits with confident but natural poses, neat styling, intentional wardrobe presentation, clean set design, and refined studio or location lighting. Keep children childlike and wholesome; do not use adult fashion, makeup, sensual posing, or mature themes. Apply the student's required Omani school uniform unless the user explicitly requests another suitable outfit.
- Do not add magazine titles, captions, logos, or fake cover text unless requested. Generated text may be inaccurate; leave clean negative space when a cover layout is intended for later editing.

## Simulated Canon camera looks

When the user asks for images “shot on Canon” or for different Canon cameras, use the camera and lens as a photographic rendering target and vary body/lens, depth of field and framing while preserving identity, uniform and scene. Examples: EOS R5 or R6 Mark II with a 50 mm or 85 mm lens for portraits, RF 24–70 mm for environmental frames, 70–200 mm for compressed candid views. Follow any model or lens the user names; otherwise pick a varied set and label each image by its simulated body/lens. These are Canon-inspired generated images, not real photographs. Show a Canon camera as a prop only when clearly requested.

## Character and editing sheets

Build the requested sheet as one organized reference image unless the user asks for separate images. Support:

- Turnaround sheet: front, side, and back full-body views at one scale and in a neutral pose.
- Expression sheet: the same face showing requested emotions.
- Pose/action sheet: distinct readable poses with stable clothing and proportions.
- Costume or accessory sheet: clear outfit views and requested detail close-ups.
- Face-camera-angle sheet: consistent head-and-shoulders views from the front, both three-quarter directions, both profiles, and optional high or low camera positions. Keep facial proportions, expression, lighting, and hairstyle stable unless a variation is requested.
- Eye-camera-angle sheet: carefully framed close-ups of the same student's eyes from frontal, three-quarter, and profile angles, with optional high or low camera positions. Preserve eye shape, iris color, eyelids, brows, and natural highlights; keep the result child-appropriate and avoid changing identity between panels.
- Editing sheet: a clean grid or sequence of the same student in planned shots, with consistent appearance, composition notes, and space for later editing. Do not imply that an image file has editable layers unless it actually does.
- Full character reference sheet: turnaround plus selected expressions, poses, and signature details.

Use a plain or unobtrusive background, even lighting, consistent anatomy, and generous spacing. Keep face and eye sheets tightly framed with every angle clearly visible. Do not rely on small generated labels; use blank panels or simple separators if needed. Preserve costume construction and Omani details without inventing elements that conflict with references.

## Storyboards

- Use the requested number of scenes or frames. If no number is given, choose a compact sequence that covers the opening, main action, and ending.
- For each frame, define the story beat, shot size, camera angle or movement, action, setting, lighting, and continuity details.
- Generate each frame separately when the user asks for storyboard images. Make one combined grid only when requested; leave clear gutters and avoid tiny text.
- Maintain character identity, wardrobe, props, setting, and time of day from frame to frame unless the story calls for a change.
- Use cinematic variety: establishing wide, medium action, close-up or reaction, and a closing view where appropriate. Do not make every frame the same angle.

## Product mockups

When asked to place a student, character, or illustration on a mug or T-shirt, preserve the supplied design as closely as possible and create a clean product presentation. Choose a useful view, such as a mug three-quarter view showing the print area or a front-facing T-shirt mockup with the artwork centered and readable. Keep the garment or product shape realistic, the printed image aligned to its surface, and the background uncluttered. If a reference design is provided, do not redraw, recolor, crop, or add text to it unless asked. Generate a mockup image, not a claim of a production-ready print file.

## A4 sticker sheets

Generate two distinct A4 portrait outputs as part of the default package:

- **Assorted student sticker sheet:** arrange varied die-cut shapes with a consistent white border and spacing, featuring the established student in different wholesome poses plus school supplies and relevant Omani school motifs. Keep stickers individually separated and inside print-safe margins.
- **Writable school-label sticker sheet:** arrange multiple repeated rectangular or softly rounded labels on an A4 page. Each label must have a large blank writing area and designated fields for “الاسم”، “الصف”، and “الشعبة” (name, grade, section/class). Keep the fields blank for handwriting unless the user provides values to print.

Use an A4 portrait proportion (210:297), an even grid, consistent cut margins, and no page background that reduces print clarity. Do not rely on image generation for small or exact Arabic lettering: create clean blank areas and, when the labels need visible Arabic field names, add those headings with reliable typesetting after image generation. Avoid claiming print-ready resolution unless the output actually meets the requested print dimensions and resolution.

## Prompt construction

Write concise prompts in this order: character identity and continuity; pose or story action; requested output type; camera and composition; setting or product; lighting; rendering style; aspect ratio. State exclusions only when they prevent likely errors, such as no text, no logo, or no watermark. Avoid contradictory directions and do not put multiple unrelated camera angles into one image unless making a sheet.

If the user asks only for prompt text, provide ready-to-use prompts with the aspect ratio and continuity notes. Otherwise, generate the requested image assets directly.
